Birden fazla seçenek

AutoChooser kullan

Left, Right veya Center gibi seçenekleri autonomousConfigure() içinde kaydet; DS'te seç ve Start ile çalıştır.

FRC'ye benzer temel fikir: bütün rutinler firmware'de hazırdır. DS'teki chooser, hangisinin çalışacağını seçer. DS'ten kaynak dosyası veya yeni kod gönderilmez.

03

İki otonomlu tam örnek

Bu kodu sketch'ine temel al; işaretli yerlere kendi motor ve sensör komutlarını ekle.

AutonomousChooser.ino
#define PROBOT_WIFI_AP_SSID     "Probot-Robot"
#define PROBOT_WIFI_AP_PASSWORD "robot1234"
#define PROBOT_WIFI_AP_CHANNEL  6
#include <probot.h>

namespace {
  uint32_t lastMessageMs = 0;

  void leftAutoInit() {
    lastMessageMs = millis();
    probot::println("LeftAuto started");
    // Sol başlangıç konumuna özel hazırlık.
  }

  void leftAutoPeriodic() {
    // Sol başlangıç sürüş/mekanizma adımları.
    if (millis() - lastMessageMs >= 1000) {
      probot::println("LeftAuto running");
      lastMessageMs = millis();
    }
    delay(20); // Her callback turu kısa sürede geri dönmeli.
  }

  void rightAutoInit() {
    lastMessageMs = millis();
    probot::println("RightAuto started");
    // Sağ başlangıç konumuna özel hazırlık.
  }

  void rightAutoPeriodic() {
    // Sağ başlangıç sürüş/mekanizma adımları.
    if (millis() - lastMessageMs >= 1000) {
      probot::println("RightAuto running");
      lastMessageMs = millis();
    }
    delay(20);
  }
}

// Boot'ta bir kez çalışır; isimler DS'te aynen görünür.
void autonomousConfigure() {
  probot::autonomous::clearRoutines();

  const bool leftAdded = probot::autonomous::addRoutine(
      "LeftAuto", leftAutoInit, leftAutoPeriodic, true);
  const bool rightAdded = probot::autonomous::addRoutine(
      "RightAuto", rightAutoInit, rightAutoPeriodic);

  if (!leftAdded || !rightAdded) {
    probot::println("AutoChooser registration failed");
  }
}

// Probot lifecycle hook'ları:
void robotInit() {
  // Motor/sensör donanımını hazırla.
  // Burada otonom kataloğunu tekrar kaydetme.
}

void robotEnd() {}
void teleopInit() {}
void teleopLoop() { delay(20); }

// Katalog doluyken seçili rutin dispatch edilir.
void autonomousInit() {}
void autonomousLoop() { delay(20); }
`true` ne demek?

Son parametresi true olan tek rutin varsayılan olur. Burada LeftAuto, başka seçim yapılmamışsa ilk seçili rutindir.

Varsayılan istemiyorsan

Hiçbir kayda true verme. Bu durumda DS'ten rutin seçilene kadar otonom Start kabul edilmez.

05

Driver Station'da dene

İlk denemede robot hareketini güvenli biçimde gözlemle.

  1. Sketch'i ESP32-S3'e derle ve yükle.
  2. Robotun Wi-Fi ağına bağlanıp Driver Station arayüzünü aç.
  3. AutoChooser listesinin rutin adlarını gösterdiğini Init öncesinde kontrol et.
  4. Örneğin RightAuto'yu seç; DS seçimi onaylayınca seçili kalır.
  5. Init'e bas. Donanım başlangıcı çalışır, chooser seçimi korunur.
  6. Autonomous açıkken Start'a bas. Seçili rutin init'i bir kez, periodic'i tekrar çağrılır.
  7. İşi bitirince Stop'a bas.
İlk donanım testi: Tekerleri yerden kaldır veya aktarma organlarını boşa al. Örnek sketch gerçek motor komutu göndermez.
06

Tek otonom varsa eski kullanım

AutoChooser eklemek zorunlu değil.

Sabit otonom
void autonomousInit() {
  // Sabit otonom için bir defalık hazırlık.
}

void autonomousLoop() {
  // Otonom hareket adımları.
  // Her turda kısa sürede geri dön.
  delay(20);
}

autonomousConfigure() yoksa Probot doğrudan global autonomousInit() ve autonomousLoop() hook'larını kullanır. Katalog doluyken bu ikisi zorunlu lifecycle hook'ları olarak tanımlı kalır; fakat seçilen rutin callback'lerini onların yerine çağıran registry dispatch eder.

07

Sık hata ve pratik kural

Chooser akışını güvenilir tutmak için.

Liste boşautonomousConfigure() tanımlı mı? Kayıtlar geçerli mi? Yeni sketch gerçekten robota yüklendi mi?
Start kabul edilmiyorDS seçimi onaylanmış mı? Varsayılan yoksa bir rutin seç. Katalog hatası varsa kimlikleri ve callback'leri düzelt.
Yanlış rutin çalıştıİsim/kimlikleri benzersiz tut; seçimi Start'tan önce yap. Çalışma sürerken chooser kilitlenir.
Robot tepki vermiyorPeriodic içinde sonsuz döngü veya uzun bloklama kullanma. Her çağrıda az iş yapıp bir sonraki tura dön.
Akılda tut: Configure katalog kurar → Init robotu hazırlar → Start seçimi sabitler → Autonomous callback'leri hareketi yürütür.
